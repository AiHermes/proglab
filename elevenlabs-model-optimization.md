# Оптимизация стоимости TTS: как мы экономим 45% на озвучке роликов и улучшили качество

## Контекст

Мы строим автоматический конвейер генерации вертикальных видео (Shorts) для продвижения крипто-аналитического сервиса. Каждый ролик — это ~420 символов русского текста, озвученного через ElevenLabs. Видео генерируется полностью автоматически: данные с сайта → нарратив через Claude AI → озвучка → монтаж через Remotion → YouTube.

Конвейер работает. Но в один момент выяснилось: **дефолтная модель в коде была выставлена на `eleven_multilingual_v2` — старую, более медленную и дорогую модель.**

## Что произошло

При разборе кода нашли строку:

```js
async function ttsEleven(text, outFile, { apiKey, voiceId, modelId = 'eleven_multilingual_v2', retries = 3 } = {}) {
```

Модель `eleven_multilingual_v2` была выбрана в момент первоначальной настройки как «стабильная». Никто не пересматривал её с тех пор. А ElevenLabs за это время выпустил новые, более дешёвые и быстрые модели.

## Эксперимент: сравниваем три модели

Сгенерировали один и тот же RU-скрипт (419 символов, 7 реплик) с тремя моделями:

| Модель | Стоимость/ролик | Стоимость/100 роликов | Качество |
|---|---|---|---|
| `eleven_multilingual_v2` (старый дефолт) | ~$0.084 | ~$8.40 | Хорошее, но медленное |
| `eleven_turbo_v2_5` | ~$0.075 | ~$7.54 | Хорошее, быстрее |
| `eleven_flash_v2_5` | ~$0.046 | ~$4.61 | ✅ Лучшее для коротких реплик |

**Итог: `eleven_flash_v2_5` на 45% дешевле старого дефолта и звучит лучше для коротких текстов (1–5 секунд).**

Одна строка фикса:

```js
// было
modelId = 'eleven_multilingual_v2'

// стало
modelId = 'eleven_flash_v2_5'
```

## Что это означает системно

Это не просто баг с моделью. Это симптом системной проблемы: **в проектах с API-зависимостями дефолты устаревают, а никто не проводит регулярный аудит стоимости.**

### Три принципа, которые мы вынесли

**1. Для каждого API-провайдера нужна таблица актуальных моделей с ценой**

Не «однажды выбрали — всегда так». У ElevenLabs, OpenAI, Gemini, Anthropic модели обновляются. Новые — дешевле и лучше. Старые — остаются в коде если не следить.

**2. Коннектор переключения моделей — не опция, а архитектурное требование**

Правильная структура:

```js
// Уровень 1: конфигурация (env или config.json)
const TTS_MODEL = process.env.ELEVEN_MODEL || 'eleven_flash_v2_5';

// Уровень 2: ограничитель — допустимые модели
const ALLOWED_MODELS = ['eleven_flash_v2_5', 'eleven_turbo_v2_5', 'eleven_multilingual_v2'];

// Уровень 3: валидация
if (!ALLOWED_MODELS.includes(TTS_MODEL)) {
  throw new Error(`Модель ${TTS_MODEL} не разрешена. Допустимые: ${ALLOWED_MODELS.join(', ')}`);
}
```

Это даёт:
- Смену модели без деплоя (через env)
- Защиту от случайной подстановки дорогой/несуществующей модели
- Явный список того, что «разрешено»

**3. Регулярные сравнительные тесты — часть процесса, не разовая акция**

Для каждого проекта с внешним AI API:
- Раз в квартал запускать сравнительный тест моделей
- Сохранять результаты: качество + стоимость + скорость
- Менять дефолт если появилась лучшая опция

## Как мы автоматизировали сравнение

Небольшой скрипт генерирует один и тот же текст через несколько моделей и считает стоимость:

```js
const MODELS = ['eleven_flash_v2_5', 'eleven_turbo_v2_5', 'eleven_multilingual_v2'];

for (const modelId of MODELS) {
  const r = await ttsEleven(text, outFile, { apiKey, voiceId, modelId });
  const charCount = text.length;
  const rate = modelId.includes('flash') ? 0.00011 : modelId.includes('turbo') ? 0.00018 : 0.0002;
  console.log(`${modelId}: ${(charCount * rate).toFixed(4)}$ за ролик`);
}
```

Запускаешь, слушаешь оба файла, выбираешь — и меняешь одну строку в конфиге.

## Итог

| | До | После |
|---|---|---|
| Модель | `eleven_multilingual_v2` | `eleven_flash_v2_5` |
| Стоимость/100 роликов | ~$8.40 | ~$4.61 |
| Экономия | — | **~45%** |
| Качество | хорошее | лучше для коротких реплик |

Простой аудит одной строки кода — $3.79 экономии на каждые 100 роликов. При масштабе 1000+ роликов в год это $37+ в год только на одном TTS-провайдере.
